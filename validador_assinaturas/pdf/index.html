🔗 Integração com Validador ITI

1. URLs geradas seguem o padrão ITI:

https://flavioluiz.github.io/validador_assinaturas/pdf/?_format=application/validador-iti+json&_secretCode=CODIGO&id=ID&type=TYPE

2. Resposta JSON para o ITI:

{
  "version": "1.0.0",
  "prescription": {
    "signatureFiles": [
      {
        "url": "https://flavioluiz.github.io/validador_assinaturas/pdf/files/arquivo.pdf"
      }
    ]
  }
}

3. Para validar:

  1. Acesse https://validar.iti.gov.br
  2. Escaneie o QR Code ou cole a URL
  3. O ITI acessará seu PDF automaticamente
  4. Validação da assinatura digital será exibida
